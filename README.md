# inbody

Парсер PDF-отчётов InBody (DDX Fitness) в JSON. Блоки «История состава тела» и
«Обмен веществ / Суточная норма калорий / Оптимальный вес / До оптимального веса» пропускаются.

```bash
pip install -r requirements.txt
python parse_inbody.py результаты/261016_inbody_result.pdf   # JSON в stdout
python parse_inbody.py результаты -o json                      # все PDF -> json/*.json
python test_parse_inbody.py                                    # проверка
```

Поддерживаются оба макета отчёта: старый (с трендом у карточек → `change`) и новый (с `inbody_score`).
Подписи частей тела в PDF — картинки, сегменты определяются по положению на странице.

## Веб-дашборд

```bash
python app.py        # http://127.0.0.1:8000
```

Страница повторяет вёрстку отчёта: выбор даты замера, история, шкалы норм, сегменты на фигуре.
Клик по любой карточке, строке шкалы, истории или части тела открывает график по всем датам
(наведение или палец — значение, клик/тап по точке — выбрать замер, колесо или щипок — масштаб,
перетаскивание или два пальца — сдвиг, двойной клик/тап — весь период; кнопки периодов; под графиком — таблица).
Таблица под графиком сортируется по столбцам, подсвечивает лучший результат мягким градиентом,
показывает изменения к прошлому замеру и от старта, перерывы между замерами; клик по строке выбирает замер.

Старт сравнения (например, после перерыва) выбирается в карточке «Изменения» или в окне графика и
хранится на сервере в `settings.json` рядом с PDF — одинаково для телефона и компьютера.
PDF читаются из `результаты/` на лету: новый файл появится после обновления страницы.
Замеры без PDF (например, с фото бумажных отчётов) лежат готовыми записями того же формата
в `результаты/manual/*.json` (на сервере — `/srv/inbody/data/manual/`); дубли дат отбрасываются.
Фигура тела берётся векторами из самого свежего PDF нового макета.

Загрузка новых отчётов — кнопка «Загрузить PDF» (или перетащить файлы на страницу).
Файл сохраняется как `ГГММДД_inbody_result.pdf` по дате замера; повтор за ту же дату отклоняется.

## Сервер

Живёт в `/srv/inbody` (Docker, `127.0.0.1:8400`), снаружи — `https://inbody.2-27-10-45.sslip.io/`
за `basic_auth` в общем Caddy. PDF лежат в `/srv/inbody/data` и переживают пересборку.

```bash
./deploy.sh                                                   # с рабочей машины: git push + обновление
ssh -i ~/.ssh/pcs_vps root@2.27.10.45 /srv/inbody/update.sh   # только обновить сервер из репозитория
```

`update.sh`: `git pull --ff-only`, `docker compose up -d --build`, ждёт `200` от `/api/data`, иначе печатает логи и падает.
